```markdown
# AI/ML Glossary

## MCP
Model Context Protocol. Open protocol by Anthropic that lets AI assistants connect to external tools and data sources via standardized JSON-RPC 2.0 messages. A client (IDE, Claude Code) connects to an MCP Server; the server exposes tools, resources, and prompts. Transport options: stdio or HTTP (SSE).

## Tool
In MCP context: a callable function exposed by an MCP server. Defined by a name, a description (used by the model to decide when to call it), and a JSON Schema for input parameters. The server returns a structured result; the model incorporates it into the next response.

## LangChain
Python (and JS) framework for building LLM-powered applications. Provides abstractions for chains, agents, memory, and tool use. Wraps multiple LLM providers (OpenAI, Anthropic, etc.) behind a unified interface.

## LangGraph
Extension of LangChain for building stateful, multi-step agentic workflows as directed graphs. Nodes are processing steps; edges define control flow (conditional or unconditional). State is typed and persisted between nodes.

## RAG
Retrieval-Augmented Generation. Technique where relevant documents are retrieved from a vector store at query time and injected into the LLM context before generation. Reduces hallucinations on domain-specific or up-to-date queries.

## Agent
An LLM that can autonomously decide which tools to call and in what order to achieve a goal. Runs in a loop: reason → call tool → observe result → reason again, until the task is complete or a stop condition is reached.

## Embedding
Dense vector representation of text that captures semantic meaning. Similar texts have geometrically close embeddings. Generated by embedding models (e.g. text-embedding-3-small). Core building block of RAG pipelines.

## Vector Store
Database optimized for storing and searching embeddings via approximate nearest-neighbor (ANN) search. Examples: Chroma, FAISS, Pinecone, pgvector.

## Chain
LangChain concept: a sequence of components (LLMs, retrievers, parsers, tools) composed together. Output of one component becomes the input of the next.

## Prompt Template
Reusable string template with named placeholders filled at runtime. Core LangChain abstraction for constructing consistent LLM inputs.

## stdio
Standard I/O transport for MCP. The server reads JSON-RPC messages from stdin and writes responses to stdout. No HTTP server needed; process lifecycle is managed by the MCP client.

## Tool Call
When an LLM decides to invoke a registered tool. Claude returns a `tool_use` block; the client executes the tool and returns the result as a `tool_result` block. The model then continues reasoning with the result in context.
```

```python
import os
import re
import subprocess
from pathlib import Path
from typing import Optional

ALLOWED_COMMAND_PREFIXES = [
    "pytest",
    "python -m pytest",
    "flake8",
    "pip check",
]

SHELL_OPERATORS = [";", "&&", "||", "|", ">", "<", "`", "$("]


def _get_project_root() -> Path:
    root = os.environ.get("PROJECT_ROOT")
    if root is None:
        return Path(__file__).parent.resolve()
    p = Path(root)
    if p.is_absolute():
        return p.resolve()
    # Relative path: resolve from tools.py location, not cwd
    return (Path(__file__).parent / p).resolve()


def _safe_path(relative_path: str) -> Optional[Path]:
    """Return resolved absolute path only if it stays inside PROJECT_ROOT."""
    root = _get_project_root()
    try:
        target = (root / relative_path).resolve()
        target.relative_to(root)  # raises ValueError if it escapes
        return target
    except (ValueError, Exception):
        return None


def read_file(path: str) -> dict:
    target = _safe_path(path)
    if target is None:
        return {"path": path, "content": None, "error": "Access denied: path escapes PROJECT_ROOT"}
    if not target.exists():
        return {"path": path, "content": None, "error": f"File not found: {path}"}
    if not target.is_file():
        return {"path": path, "content": None, "error": f"Not a file: {path}"}
    try:
        return {"path": path, "content": target.read_text(encoding="utf-8"), "error": None}
    except Exception as e:
        return {"path": path, "content": None, "error": str(e)}


def search_files(query: str, search_path: str = ".") -> dict:
    target_dir = _safe_path(search_path)
    if target_dir is None:
        return {"query": query, "matches": None, "error": "Access denied: path escapes PROJECT_ROOT"}
    if not target_dir.exists():
        return {"query": query, "matches": None, "error": f"Directory not found: {search_path}"}
    matches = []
    try:
        for file_path in sorted(target_dir.rglob("*")):
            if not file_path.is_file():
                continue
            try:
                lines = file_path.read_text(encoding="utf-8", errors="ignore").splitlines()
                for i, line in enumerate(lines, 1):
                    if query.lower() in line.lower():
                        rel = str(file_path.relative_to(_get_project_root()))
                        matches.append({"file": rel, "line": i, "text": line.strip()})
            except Exception:
                pass
        return {"query": query, "matches": matches, "error": None}
    except Exception as e:
        return {"query": query, "matches": None, "error": str(e)}


def _is_allowed_command(command: str) -> bool:
    cmd = command.strip()
    if any(op in cmd for op in SHELL_OPERATORS):
        return False
    return any(cmd.startswith(prefix) for prefix in ALLOWED_COMMAND_PREFIXES)


def run_tests(command: str) -> dict:
    if not _is_allowed_command(command):
        return {
            "command": command,
            "output": None,
            "status": "error",
            "error": f"Command not allowed. Allowed prefixes: {ALLOWED_COMMAND_PREFIXES}",
        }
    try:
        proc = subprocess.run(
            command.split(),
            capture_output=True,
            text=True,
            timeout=60,
            cwd=_get_project_root(),
        )
        return {
            "command": command,
            "output": proc.stdout + proc.stderr,
            "status": "success" if proc.returncode == 0 else "failure",
            "error": None,
        }
    except subprocess.TimeoutExpired:
        return {"command": command, "output": None, "status": "error", "error": "Timed out after 60s"}
    except Exception as e:
        return {"command": command, "output": None, "status": "error", "error": str(e)}


def get_doc(term: str, glossary_path: Optional[str] = None) -> dict:
    if glossary_path is None:
        glossary_path = str(Path(__file__).parent / "docs" / "glossary.md")
    try:
        content = Path(glossary_path).read_text(encoding="utf-8")
    except Exception as e:
        return {"term": term, "description": None, "error": str(e)}

    pattern = re.compile(r"^## (.+)$", re.MULTILINE)
    sections = list(pattern.finditer(content))

    for i, match in enumerate(sections):
        heading = match.group(1).strip()
        if heading.lower() == term.lower():
            start = match.end()
            end = sections[i + 1].start() if i + 1 < len(sections) else len(content)
            return {"term": heading, "description": content[start:end].strip(), "error": None}

    available = [m.group(1) for m in sections]
    return {"term": term, "description": None, "error": f"Term '{term}' not found. Available: {available}"}
```

```python
import logging
import os
from pathlib import Path

from dotenv import load_dotenv
from mcp.server.fastmcp import FastMCP

from tools import get_doc, read_file, run_tests, search_files

load_dotenv()

logging.basicConfig(
    level=logging.INFO,
    format="[%(asctime)s] %(levelname)s %(message)s",
    datefmt="%H:%M:%S",
    handlers=[logging.StreamHandler()],  # stderr only, keeps stdout clean for MCP
)
log = logging.getLogger("mcp-server")

GLOSSARY = str(Path(__file__).parent / "docs" / "glossary.md")

mcp = FastMCP("homework-mcp")


@mcp.tool()
def tool_read_file(path: str) -> dict:
    """Read a file from the project directory (sandboxed to PROJECT_ROOT).

    Use relative paths only (e.g. 'src/main.py', 'README.md').
    Returns file content as a string.
    """
    log.info("tool=read_file path=%s", path)
    result = read_file(path)
    if result["error"]:
        log.error("tool=read_file status=error error=%s", result["error"])
    else:
        log.info("tool=read_file status=success bytes=%d", len(result["content"]))
    return result


@mcp.tool()
def tool_search_files(query: str, search_path: str = ".") -> dict:
    """Search for text across files in the project directory (case-insensitive).

    Sandboxed to PROJECT_ROOT. Returns list of {file, line, text} matches.

    Args:
        query: Text to search for
        search_path: Subdirectory to search in (default: project root '.')
    """
    log.info("tool=search_files query=%r path=%s", query, search_path)
    result = search_files(query, search_path)
    if result["error"]:
        log.error("tool=search_files status=error error=%s", result["error"])
    else:
        log.info("tool=search_files status=success matches=%d", len(result["matches"]))
    return result


@mcp.tool()
def tool_run_tests(command: str) -> dict:
    """Run a whitelisted test/lint command in the project directory.

    Allowed prefixes: pytest, python -m pytest, flake8, pip check.
    Shell operators (;, &&, |, etc.) are blocked for safety.

    Args:
        command: Command to run (e.g. 'pytest tests/ -v', 'flake8 .')
    """
    log.info("tool=run_tests command=%r", command)
    result = run_tests(command)
    log.info("tool=run_tests status=%s", result["status"])
    if result["error"]:
        log.error("tool=run_tests error=%s", result["error"])
    return result


@mcp.tool()
def tool_get_doc(term: str) -> dict:
    """Get the definition of an AI/ML term from the local glossary.

    Available terms: MCP, Tool, LangChain, LangGraph, RAG, Agent,
    Embedding, Vector Store, Chain, Prompt Template, stdio, Tool Call.

    Args:
        term: Term to look up (case-insensitive, e.g. 'RAG', 'mcp', 'Agent')
    """
    log.info("tool=get_doc term=%r", term)
    result = get_doc(term, GLOSSARY)
    if result["error"]:
        log.error("tool=get_doc status=error error=%s", result["error"])
    else:
        log.info("tool=get_doc status=success term=%s", result["term"])
    return result


if __name__ == "__main__":
    log.info("Starting homework-mcp server (stdio)")
    log.info("PROJECT_ROOT=%s", os.environ.get("PROJECT_ROOT", "(not set — using server.py dir)"))
    mcp.run(transport="stdio")
```

# Homework 5 — MCP Server

## Как работает MCP

**Model Context Protocol (MCP)** — открытый протокол Anthropic, который позволяет IDE или агенту (клиенту) подключаться к внешнему MCP-серверу через стандартизированные JSON-RPC 2.0 сообщения. В этом проекте используется транспорт **stdio**: сервер читает запросы из `stdin` и отвечает в `stdout`. Клиент (Claude Code) запускает процесс сервера сам и управляет его жизненным циклом.

**Tool** — зарегистрированная функция на сервере с именем, описанием и JSON Schema параметров. Языковая модель видит список инструментов при инициализации и самостоятельно решает, когда и какой вызвать, на основе описания. Сервер получает вызов, выполняет логику, возвращает структурированный JSON-результат — модель включает его в следующий ответ.

## Инструменты

| Tool | Описание |
|------|----------|
| `tool_read_file(path)` | Читает файл из PROJECT_ROOT. Только относительные пути. |
| `tool_search_files(query, search_path?)` | Поиск текста по файлам проекта (case-insensitive). |
| `tool_run_tests(command)` | Запускает pytest / flake8 / pip check. Вайтлист + блокировка shell-операторов. |
| `tool_get_doc(term)` | Возвращает определение AI/ML термина из `docs/glossary.md`. |

## Безопасность

- **Sandbox**: `read_file` и `search_files` ограничены директорией `PROJECT_ROOT` (env var). Любой путь, выходящий за её пределы через `../` или абсолютный путь, блокируется.
- **Whitelist команд**: `run_tests` принимает только команды с префиксами `pytest`, `python -m pytest`, `flake8`, `pip check`.
- **Блокировка shell-инъекций**: символы `;`, `&&`, `|`, `>`, `` ` ``, `$(` запрещены в строке команды.
- **Логи без секретов**: в лог пишутся имя tool, входные параметры и статус; содержимое файлов и вывод команд не логируются.
